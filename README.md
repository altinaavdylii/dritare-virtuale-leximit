# dritare-virtuale-leximit
Aplikacion web për bibliotekë me module user dhe admin, leximi dhe shkarkimi i librave online.
👤 Përdoruesit
- Regjistrim dhe login i sigurt.
- Leximi i librave direkt online në dritare virtuale.
- Shkarkimi i librave në format PDF.
- Dërgimi i feedback-ut për platformën.

### 👨‍💼 Administratori
- Menaxhimi i librave (shtim, modifikim, fshirje).
- Shikimi i përdoruesve të regjistruar.
- Marrja e feedback-ut nga përdoruesit.
- Raporte mbi leximin e librave.

---

## 🛠 Teknologjitë e përdorura
- **Frontend**: HTML, CSS, Bootstrap  
- **Backend**: PHP  
- **Database**: MySQL  
- **Dizajn**: Animacione CSS për UI moderne
